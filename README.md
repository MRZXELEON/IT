# IT Messenger & Shop

Многофункциональное приложение для общения с элементами магазина и внутренней экономикой.

## Возможности

- **Чаты** – отправка текстовых, голосовых и видеосообщений (кружков), фото и видеофайлов, стикеров.
- **Магазин** – покупка товаров/курсов за внутреннюю валюту ITcoin.
- **Профили** – изменение аватара, логина, пароля, просмотр истории покупок.
- **Смена аккаунтов** – быстрый переход между несколькими учётными записями.
- **Редактирование и удаление сообщений**, закрепление сообщений, ответы на сообщения.
- **Поиск по чатам**, создание новых чатов.
- **Полноэкранный просмотр фото/видео**, встроенный видеоплеер.

## Технологии

- **Kotlin** + **Jetpack Compose** (Material 3)
- **Room** – локальная база данных
- **Coil** – загрузка изображений
- **ExoPlayer** – воспроизведение видео
- **Coroutines + Flow** – асинхронность
- **MVVM** – архитектура
